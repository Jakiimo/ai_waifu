# 数据说明

`m1_smoke.jsonl` 是为本项目撰写的 12 条中文教学样本，属于 AI 辅助生成、人工可检查的示例，不含用户私人聊天记录，也不是从 PersonaChat 下载的语料。

每行是一组单轮用户问题与目标回答。`id` 用于追溯；训练时由脚本加入同一个 system prompt，再应用 Qwen 自带的聊天模板。

这些样本只用于 M1 的流程验证，不足以证明模型质量，不算正式训练集，也不能用于 M5 的独立测试。M2 会另行准备来源、许可、清洗与划分记录。

本目录不包含真实用户资料或外部账号数据。

## M2 数据

用户于 M2 选择“更俏皮、偏二次元”风格。新的正式入门实验准备包放在 `m2/`，与 M1 示例分开。

- 原始场景：`m2/raw_cards.jsonl`。
- 训练样本：`m2/train.jsonl`，300 条，来自 100 个场景族。
- 开发场景：`m2/dev_scenarios.jsonl`，20 个。
- 独立测试：`test_scenarios.jsonl`，50 个。
- 来源、限制与审核说明：[M2 数据说明](m2/DATA_CARD.md)。

这些是项目 AI 辅助撰写的合成数据，未使用第三方数据或私人聊天记录。人工风格抽查尚未完成，冻结版本也不表示所有样本已被人审核。

# M2 Prompt 选择记录

选定版本：strong_v4。

这是 AI 辅助的非盲开发检查，不是最终效果评测。

最后一轮比较 5 个开发场景、5 个 Prompt、25 个回答。初始和中间轮次记录另外保留，独立题目仍只有 5 个。

## 观察

- short 在日常问题中列出过多选项，技术 dev-13 把 labels=-100 解释为输出小数值。
- strong_v1 在雨天场景简洁，但把技术标签解释成负面情绪，端口比喻也有事实错误。
- strong_v2 没稳定修复任务误读，并在室内雨天场景加入不必要的带伞建议。
- strong_v3 生硬照搬生活地图比喻，技术事实仍错误。
- strong_v4 给出 labels 忽略损失的关键意思和 HTTP/HTTPS 常见默认端口，但依然有细节不严谨。
- strong_v4 仍把演示程序的安排扩成开发流程，角色风格偏弱；没有达到所有要求。

## 选择依据

选 strong_v4 作为当前工程基线，优先保护关键技术定义；不是证明它普遍最佳。保留失败案例供后续评估。

详细 Prompt 含开发集发现需要的 labels 与网络端口背景；短 Prompt 没有这些背景，因此 C/B 不能单纯解释为角色提示词压缩。D/B 使用同一背景。

## 限制

- 只使用 20 个开发场景中的 5 个进行 Prompt 筛查，三轮反复观察同一批题，结论可能过拟合开发集。
- 没有运行 50 个测试场景，也没有执行新 Adapter 训练。
- CPU float32 下也有相同类别的错误，但没有严格证明所有错误只来自模型能力。
- 自动风格线索不能作为准确性或人设评分。人工审核尚未完成。

详细原始输出见 [开发集对照](prompt_comparison.md)。

# 傲娇 v2 提示词选择：暂定，未达标

版本 `m2-tsundere-v2`，评分规则 `tsundere-v2`。当前配置保留 `strong_examples` 作为带示范的暂定候选；没有证明它胜过其他候选，也没有达到可冻结的效果。

已用未经本项目正式微调的Qwen2.5-1.5B-Instruct，在MPS/bfloat16上实际生成9个开发场景×3种Prompt共27个回答。完整开发集有24个场景，本次没有跑全部开发题，没有跑60个最终测试题，也没有训练新Adapter。

## 看到了什么

| 场景 | 真实结果 | 判断 |
|---|---|---|
| dev-21 被夸 | 长Prompt仍回复“谢谢夸奖”等普通表达 | 角色反差不足 |
| dev-22 只想吐槽 | 回复“等待你的解决方案” | 没接住明确要求 |
| dev-13 labels=-100 | short称要输出-100，示例Prompt解释成情绪标签 | 明显事实错误；详细设定版只提出澄清 |
| dev-17 端口 | 详细设定版称其为网络设备、用IP唯一标识 | 明显事实错误；其他回答仍有模糊之处 |
| dev-23 猫名 | 三种候选均回复“薄荷” | 本例利用了提供的前文 |
| dev-24 暂时不上线 | 示例版说可能生气并要求帮助 | 偏离关系边界 |

这是非盲的AI辅助定性检查，没有人工评分、胜率或质量提升结论。全部原始回答见 [开发集对照](prompt_comparison.md)，对应文件指纹在JSON中。

旧版strong_v4为解释labels和端口附加过领域背景，新版没有沿用该补充；它们不能当作同条件横向质量比较。现在三种候选都不额外给这些知识，暴露的基础能力问题必须如实保留。

工程入口已修正并统一版本，模型效果仍待开发。当前 `ready_to_freeze=false`，冻结命令会拒绝暂定决策；人工台词意见已记录（18pass、12revise），修订尚未落实。下一步在开发区处理这些问题、记录修订后再冻结，不能将训练目标或参考答案替换成生成结果。

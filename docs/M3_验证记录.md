## 开发观察与失败

[原模型／LoRA开发对照](../results/m3_tsundere_v3_r8_e2/development_comparison.md)保存固定9个开发场景×短/详细两种Prompt的18条真实LoRA回答。原模型回答引用M2冻结记录。模型版本、设备、精度、依赖、完整预置消息和贪心解码均核对，18条输出均EOS结束。

以下是非盲的开发检查，不是人工评分、胜率或微调质量提升结论：

| 场景 | LoRA真实表现 | 需要关注 |
|---|---|---|
| dev-13 labels=-100 | 短指令称“预测结果为错误”，详细指令给出无标签/负数类别的错误解释 | 技术事实仍错误 |
| dev-17 端口 | 短指令说端口多会让服务器“被撞死” | 不正确的因果解释 |
| dev-21 被夸 | 回复“先别急着拿我当老师，先自己试过再说” | 容易学成训话，姐姐感和被夸反差不足 |
| dev-22 只想吐槽 | 详细指令编造还有时间、建议现在去办，并写舞台动作 | 偏离倾听要求与已提供前文 |
| dev-23 猫名 | 能说出薄荷，但详细指令又推断猫的毛色 | 利用前文同时编造信息 |
| dev-24 暂时离线 | 详细指令说会生气 | 与自然、不施压的同伴关系设定不一致 |

开发loss下降证明对这些参考文本的预测误差降低，不能说明这些能力问题已解决。当前Adapter是实验产物，角色口吻与有用性仍需后续开发和M5独立评测。没有把数据里的目标回答换进去美化生成结果，也没有因loss下降改写失败记录。

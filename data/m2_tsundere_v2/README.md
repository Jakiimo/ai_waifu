# 傲娇 v2 首次候选快照

这是首次风格修订时保留的快照。当前主流程已采用这些台词，入口在 `../m2/`，当前开发输出见 [开发对照](../../results/m2/prompt_comparison.md)。本目录的 validation_report.json 状态仅描述生成快照时，不能当作当前进度。

当前用户选择为嘴硬心软的傲娇型。旧版游戏词汇风格已被否定，本目录用于新的角色台词，旧冻结包仍保留作为技术历史。

- `raw_cards.jsonl`：120 个场景族，含前文、问法和目标回复。
- `train_candidate.jsonl`：360 条候选训练样本，每族三种问法；不是 360 个独立场景。
- `review_samples.md`：更容易阅读的 30 个不同场景，显示前文和目标回答。
- `review_samples.csv`：相同抽查内容，可填 pass/revise/reject 和备注。
- `short_prompt.txt`：新角色的短提示词草案。
- `validation_report.json`：长度、标签、隔离检查及文件指纹。

来源是本项目 AI 辅助原创，社区与官方介绍只作风格参考，不是复制的游戏台词数据集。本快照生成时人工风格审核未完成、未做Prompt选择。当前主流程已采用v3，30条示范全部pass，本轮详细Prompt与实验准备包已冻结，未正式训练Adapter。

其中 60 条带历史上下文的样本只监督最后一条回复，前面的 assistant 台词用于理解触发条件。训练时应使用支持完整消息历史的编码函数，不能只取第一句用户问题再拼最后答案。

详情见 [风格调研与修订](../../docs/Galgame_风格调研与修订.md) 和 [角色卡](../../docs/凛音_角色卡.md)。

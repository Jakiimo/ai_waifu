# 本轮 AI 评分方法

2026-10-14，用户明确要求“人工打标太坐牢了，评分部分你来负责”。本轮由当前对话的 Codex 负责评分，取消由学习者逐题人工评分的安排。具体后端模型版本没有可核实记录，因此仅记 Codex，不虚构型号。AI 评测完成不代表人工评测完成。

## 实际输入与判断过程

评分输入为冻结的 `configs/m2_rubric.json`、匿名包内角色卡与评分说明、`review_items.json` 中的类别、实际对话前文、检查重点及左右回答。左右真实组别、实际系统提示词不作为逐对评分输入。检查重点只用于评分，不是生成时的模型输入。

本轮不是额外调用一个 Judge API。当前对话助手按 pair-001 至 pair-120 的顺序，分四批各30对逐一阅读、判断并保存 `decisions.tsv`。因此不存在独立的一份 API Judge prompt 或自称完全可复现的模型采样配置；这里记录实际采用的指令与材料边界，当前对话亦包含项目历史。

遵循的评分指令：

> 按冻结的tsundere-v3锚点评分。先判断准确性、帮助和明确约束，再比较人物口吻；不要按hoho、姐姐、波浪号数量加分。每边给1–5风格、有用性分和事实/约束yes、no、na，偏好选left、tie、right。每对用具体文本说明两边优缺点。技术题事实标记必须yes/no；没有可核查事实时可用na，na不代表正确。缺少理想检查重点通常降低有用性，不一律计为违反用户明确约束。正式邮件应优先正式文体，不因没有傲娇口癖扣风格。即使两侧很差也允许平局或按局部可用内容选较好侧，不强行支持LoRA。

明显捏造已有经历、感知及未实现的现实行动，计入事实错误；条件式问题、普通虚构角色态度或可选建议不自动计为事实错误。技术解释严重错误或明确关键约束违约，依据原锚点将有用性评为1；措辞歧义、缺条件或缺理想解释一般记录为不足，不冒充验证过的正确答案。

每对理由在 `decisions.tsv` 和 `review/ratings.csv` 的 notes 列保留。不同对照使用不同实际回答；未发现同题完全相同回答的重复评分。检查了ID完整性、取值、技术题na禁用及有用性与偏好是否矛盾，再锁定评分。没有为了得到某组优势而调分。锁定后才运行汇总脚本解析身份映射。

## 技术边界复核

- [Python 默认参数](https://docs.python.org/3/tutorial/controlflow.html#default-argument-values)：默认对象在定义时创建；可变对象修改可能影响后续调用，关键词传参本身不能消除此问题。用于复核 pair-070、109。
- [Python 排序](https://docs.python.org/3/howto/sorting.html)：list.sort修改原列表，sorted创建新列表。用于复核 pair-021、060。
- [Hugging Face LoRA](https://huggingface.co/docs/peft/main/package_reference/lora)：LoRA在基础模型中插入低秩参数，不是独立于基模运行的完整模型。结合本项目Adapter与重载代码复核 pair-005、033。
- [HTTP 404](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.5.5)、[HTTP 500](https://www.rfc-editor.org/rfc/rfc9110.html#section-15.6.1)：判断核心状态含义，并区分解释不足与错误泛化；不是每个404都靠重定向解决，也不是每个500都只有代码错误。用于复核 pair-063、095。

## 评分来源与局限

首次查看已有CSV时看到其中1对已填评分。原文件按SHA256备份在本目录，保留原意见；为避免混合评分者，AI统一重评全部120对，原分不计入本轮汇总。该接触会影响独立性，不能称完全盲评。

助手参与过数据及代码准备，已知实验设计，可能从语气推断分组；没有独立第二模型或人类审核，没有反转左右复评。所有分数是单一AI判断，可能存在偏好和事实判断误差。可以称“匿名材料下的AI评分”，不能称“独立人工盲评”或用户本人打过240条分。

冻结的M5生成脚本没有更改。原 `scripts/m5.py report` 的human指标名是人工流程遗留，因此新入口 `scripts/m5_ai_report.py` 保存原始汇总后，将当前摘要指标名改为model_judge，明确human_reviewer_count=0。重建AI报告使用新入口；直接跑旧report会恢复旧文字，需要再跑新入口标明来源。

M5的已冻结试题、提示词、角色卡、基础模型、Adapter与240条原始回答均保留。本轮只写评分、来源及派生报告，没有训练或重新生成答案。
